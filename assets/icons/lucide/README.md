# QUANTUM Lucide icon subset

This directory contains an unmodified, curated subset of Lucide SVG icons for
QUANTUM CoasterWorks editor controls. The files were copied from
`assets/_vendor/lucide/icons/` at upstream commit
`eb3c04d059d92903f992f0d3b7c732deca6da7a5`.

Lucide is distributed under the ISC license. Some Lucide icons are derived
from Feather and are covered by the MIT notice included in `LICENSE`. Retain
that file when redistributing these SVGs.
