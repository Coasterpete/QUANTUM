# Ground assets

Ground Surface M0 loads package-relative PNG maps from this folder. An
authored value such as `assets://ground/my-surface.png` resolves to
`assets/ground/my-surface.png` beneath the runtime asset root; an identifier
outside this folder is rejected.

The three files here are **synthetic diagnostic test patterns, not art**. They
exist so the import path, UV tiling, and per-map shading can be demonstrated and
regression-checked without shipping a real-world surface material. They are
generated by [`tools/make_ground_test_textures.py`](../../tools/make_ground_test_textures.py);
regenerate rather than hand-editing them.

| File | Slot | Encoding | Purpose |
| --- | --- | --- | --- |
| `test-ground-albedo.png` | Albedo | sRGB | Tinted quadrants, 16-texel checker, red border; makes tiling, rotation, and stretching obvious in a screenshot |
| `test-ground-normal.png` | Normal | Linear | Tangent-space normal map derived from the same pattern, so the two line up under tiling |
| `test-ground-roughness.png` | Roughness | Linear | Multiplier map alternating matte and glossier patches |

Supply your own ground material by dropping PNG files into this folder and
selecting them in **View Settings → Ground Surface**. The built-in fallback is
used whenever no map is selected or a selected map cannot be read; the Editor
reports which one is active.
